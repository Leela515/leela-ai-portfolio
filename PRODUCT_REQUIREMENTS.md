# Leela AI Portfolio — Product Requirements

# Overview

I am building this portfolio as a production-style AI engineering project instead of traditional static portfolio website.

The goal is not only to showcase my projects and experience, but also to demonstrate how I design and build real-world AI systems using:

* Retrieval-Augmented Generation (RAG),
* backend APIs,
* vector search,
* evaluation pipelines,
* and deployment infrastructure.

This portfolio itself will function as an AI product.

Recruiters, engineers, and hiring managers will be able to:

* explore my projects,
* inspect system architectures,
* and interact with an AI assistant that answers questions grounded in my portfolio content.

---

# Goals

The primary goals of this project are:

* Build a production-style AI portfolio platform
* Demonstrate practical AI engineering skills
* Showcase real-world RAG system design
* Demonstrate backend and deployment knowledge
* Present projects in an interactive and technical way
* Create a portfolio that itself becomes a flagship project

---

# Core Features

## AI Recruiter Assistant

A RAG-based assistant capable of answering questions about:

* my projects,
* technical decisions,
* architecture choices,
* research work,
* and engineering experience.

The assistant should provide grounded answers using retrieved portfolio content.

---

## Project Showcase

The portfolio will contain detailed technical breakdowns of projects including:

* problem statement,
* architecture,
* implementation details,
* evaluation strategies,
* deployment setup,
* and engineering trade-offs.

---

## Resume-Aware Retrieval

The retrieval system will use:

* resume content,
* project documentation,
* architecture notes,
* and technical writeups

to answer recruiter and engineering questions.
