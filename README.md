# Leela AI Portfolio

A production-style AI portfolio platform built to showcase applied AI engineering, Retrieval-Augmented Generation (RAG), backend systems, and real-world machine learning projects.

I am designing this project as an interactive AI system where recruiters, engineers, and hiring managers can:

* explore projects,
* inspect technical architectures,
* and interact with a recruiter-focused AI assistant grounded in my portfolio content.

---

# Features

## AI Recruiter Assistant

A RAG-powered assistant capable of answering questions about:

* projects,
* technical decisions,
* architecture choices,
* research work,
* and engineering experience.

---

## Production-Oriented Architecture

The portfolio is designed using a modular AI system architecture including:

* frontend application,
* backend APIs,
* retrieval pipeline,
* vector search,
* and grounded answer generation.
